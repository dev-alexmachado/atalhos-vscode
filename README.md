## Acesso a ferramentas do VSCode

- `Ctrl+,`: configurações.
- `Ctrl+-` ou `+`: zoom da janela.
- `Ctrl+Alt+;`: abre navegador de Internet do VSCode.
- `Ctrl+Alt+I`: abre o chat do copilot.
- `Ctrl+B`: abre/fecha barra lateral primária.
- `Ctrl+P`: procura e abre arquivos rapidamente pelo nome.
- `Ctrl+Shift+X`: extensões.
- `F1` ou `Ctrl+Shift+P`: acessa paleta de comandos do VSCode.
- `F11`: tela inteira.

## Código-fonte

- `Alt+Clique`: adiciona um novo cursor no local exato onde você clicou.
- `Alt+↓` ou `↑`: move linha para cima ou para baixo.
- `Ctrl+;`: insere linha de comentário ou transforma código selecionado em comentário.
- `Ctrl+A`: seleciona tudo.
- `Ctrl+D`: seleciona a próxima ocorrência igual à palavra atual.
- `Ctrl+F`: localiza texto no arquivo atual.
- `Ctrl+F5`: executa sem depuração.
- `Ctrl+Shif+F`: pesquisa termos em todos os arquivos do projeto.
- `Ctrl+Shift+K`: apaga a linha inteira.
- `Ctrl+Shift+L`: seleciona todas as ocorrências da palavra ou seleção atual de uma vez.
- `Shift+Alt+↓` ou `↑`: duplica linha de código selecionada.
- `Shift+Alt+F`: corrige a indentação do código-fonte.
- `F5`: inicia a depuração.
- `F12`: vai direto para a definição de uma função ou variável.

## Pastas e arquivos

- `Ctrl+Alt+Win+N`: novo arquivo.
- `Ctrl+Shift+N`: nova janela.
- `Ctrl+K+S`: salvar tudo.
- `Ctrl+O`: abrir arquivo.
- `Ctrl+S`: salvar arquivo.
- `Ctrl+Shift+S`: salvar como.
- `F2`: renomeia um símbolo e atualiza todas as suas referências no código.

## Terminal

- `Ctrl+5`: dividir o terminal.
- `Ctrl+C`: interrompe a execução de comando no terminal.
- `Ctrl+'`: alterna cursor do teclado entre código-fonte e terminal.
- `Ctrl+J` ou `Ctrl+Shift+'`: abre/oculta terminal.
