# Atalhos Visual Studio Code

## Código-fonte

- `Shift+Alt+↓` ou `↑`: duplica linha de código selecionada.
- `Alt+↓` ou `↑`: move linha para cima ou para baixo.
- `Ctrl+;`: insere linha de comentário ou transforma código selecionado em comentário.
- `F5`: inicia a depuração.
- `Ctrl+F5`: executa sem depuração.
- `Ctrl+A`: seleciona tudo.

## Terminal

- `Ctrl+J`: abre/oculta terminal.
- `Ctrl+'`: alterna cursor do teclado entre código-fonte e terminal.
- `Ctrl+C`: interrompe a execução de comando no terminal.

## Acesso a ferramentas do VSCode

- `Ctrl+Alt+;`: abre navegador de Internet do VSCode.
- `Ctrl+Alt+i`: abre o chat do copilot.
- `F1` ou `Ctrl+Shift+p`: acessa paleta de comandos do VSCode.
- `Ctrl+B`: abre/fecha barra lateral primária.
- `F11`: tela inteira.
